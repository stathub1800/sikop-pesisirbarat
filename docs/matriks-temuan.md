## Sisa risiko

1. **Batas wilayah indikatif.** Batas berasal dari data turunan BIG, bukan peta Wilkerstat BPS. Ganti file di
   `data/raw/batas-kecamatan/` dengan batas resmi, lalu jalankan workflow Data.
2. **Pekon (S01).** Batas dan daftar pekon belum tersedia; pencarian pekon menunggu data MFD.
3. **Domain go.id (S10).** Hosting sudah di Cloudflare; pemetaan ke subdomain go.id perlu koordinasi Diskominfo.
